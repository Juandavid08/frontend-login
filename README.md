Para probar el FRONTEND se debe instalar las dependencias, así:

Instalar dependencias:

npm install


Este comando descargará las bibliotecas y herramientas necesarias para ejecutar la aplicación.

Ejecutar la aplicación:

Para iniciar la aplicación en tu máquina local, ejecuta:

npm start

Esto abrirá una ventana de tu navegador con la aplicación funcionando en http://localhost:3000
